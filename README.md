Run the same lighting effect on your keyboard, LED strips and the lights behind your monitor. Show an image, animation or temperatures on a compatible LCD. Your lights stay on when you close the editor.

**[Get Windows Setup](https://376east.github.io/prismestra/?download=1)** · [Find your device](https://376east.github.io/prismestra/devices/) · [Get help](#get-help) · [Русский](README.ru.md)

Setup works on Windows 10 version 1903 or later and Windows 11 (x64). It comes with OpenRGB for supported PC lighting. [All release files](https://github.com/376east/prismestra/releases/latest)

## Get started

1. Run the downloaded installer.
2. Open Prismestra. It starts a scene on the lights it sets up automatically. Check **Devices** for any lights that need a setup step.
3. To change the effect, choose a scene and click **Apply**.

You can keep FanControl running for cooling. If another app controls the same lights, turn off lighting control for those devices in one of the apps. For smart lights, follow the connection or sign-in steps. [Installation guide](docs/windows-installer.md)
