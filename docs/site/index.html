Your first scene

Setup includes OpenRGB for supported PC lighting.

  1. Install Prismestra

    Run Setup and open the app. It searches for supported lights and starts a scene on the ones it can set up automatically.

  2. Check your lights

    Open Devices to see what’s connected and what still needs setup.

  3. Pick a scene

    Choose an effect in Scenes and select Apply. The lights keep running when you close the editor.
