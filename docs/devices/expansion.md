# Device compatibility backlog

[Device catalog](prismestra.json) · [Compatibility and evidence levels](https://github.com/376east/prismestra/blob/550017bb09f933a653ef113290c55137b469cf78/docs/compatibility.md#what-counts-as-support)

Record the model, hardware revision, firmware, OS, connection and Prismestra commit for each run. Specify which outputs were observed on the device. Sanitize device reports before publishing. A fixture can establish parser and worker behavior. Physical acceptance requires a visible result on the named model and revision.
