# Security policy

[Report a vulnerability privately on GitHub](https://github.com/376east/prismestra/security/advisories/new). Include the Prismestra version, the affected component, and steps to reproduce the issue. Remove credentials, tokens and personal device identifiers from the report.

For installation failures, device compatibility or other ordinary bugs, use the [public issue forms](https://github.com/376east/prismestra/issues/new/choose).
