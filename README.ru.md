# Prismestra

[English](README.md) · **[Скачать Windows Preview 6](https://github.com/376east/prismestra/releases/download/v0.1.0-preview.6/Prismestra-Setup-0.1.0.6-x64.exe)** · [Совместимость](docs/compatibility.md)

Объединяет подсветку ПК, поддерживаемые Bluetooth-ленты, LCD и домашнее освещение в одной сцене. После закрытия редактора сцена продолжает работать.

## Установка

Запустите установщик Windows x64 и выберите, нужен ли автозапуск при входе. В комплекте фоновый OpenRGB и необходимые компоненты Windows. [Настройка и разрешения](docs/windows-installer.md)

**Preview 6:** Перед импортом ZIP-профиля остановите вывод на устройства. Эта версия может отправить цвета профиля до нажатия «Применить». [Что изменилось и известные проблемы](https://github.com/376east/prismestra/releases/tag/v0.1.0-preview.6)
