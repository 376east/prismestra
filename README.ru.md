Запустите один эффект на клавиатуре, LED-ленте и подсветке за монитором, а на совместимом LCD оставьте температуры. Prismestra работает в Windows и продолжает выводить сцену после закрытия редактора.

**[Установщик для Windows](https://376east.github.io/prismestra/?download=1&lang=ru)** · [Найти устройство](https://376east.github.io/prismestra/devices/?lang=ru) · [Помощь](#помощь) · [English](README.md)

Установщик подходит для 64-разрядных Windows 10 и 11. В него входит OpenRGB, который в фоне управляет совместимой подсветкой ПК. [Все файлы релиза](https://github.com/376east/prismestra/releases/latest)

## Как начать

1. Запустите скачанный установщик.
2. Откройте Prismestra. Она ищет устройства и запускает сцену на подсветке, которую может настроить автоматически. Откройте «Устройства», чтобы увидеть, что подключилось и что ещё нужно настроить.
3. Чтобы сменить эффект, выберите сцену и нажмите «Применить».

FanControl может продолжать управлять охлаждением. Если две программы управляют одной подсветкой, выберите, какой из них отдать этот свет. Для домашнего освещения может понадобиться подключение к сети или вход в аккаунт. [Руководство по установке](docs/windows-installer.md)
