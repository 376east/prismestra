Запустите один эффект на клавиатуре, светодиодных лентах и подсветке за монитором. На совместимом LCD можно показать картинку, анимацию или температуры. Подсветка продолжит работать после закрытия редактора.

**[Установщик для Windows](https://376east.github.io/prismestra/?download=1&lang=ru)** · [Найти устройство](https://376east.github.io/prismestra/devices/?lang=ru) · [Помощь](#помощь) · [English](README.md)

Поддерживаются Windows 10 версии 1903 и новее и Windows 11 (x64). OpenRGB для управления совместимой подсветкой ПК уже входит в установщик. [Все файлы релиза](https://github.com/376east/prismestra/releases/latest)

## Как начать

1. Запустите скачанный установщик.
2. Откройте Prismestra. Сцена запустится на устройствах, которые настроились автоматически. В разделе «Устройства» видно, что ещё нужно настроить.
3. Чтобы сменить эффект, выберите сцену и нажмите «Применить».

FanControl можно оставить включённым для управления охлаждением. Если две программы управляют одной и той же подсветкой, отключите управление этими устройствами в одной из них. Для умного света следуйте подсказкам по подключению или входу в аккаунт. [Руководство по установке](docs/windows-installer.md)
